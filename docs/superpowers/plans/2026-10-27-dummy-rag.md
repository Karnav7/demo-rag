# dummy-rag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React financial-crime Graph-RAG investigation assistant with Lattice's feature set, running fully in the browser on a realistic mock Neo4j-shaped dataset. It is restyled with the Quiet Paper and Midnight Glass themes and calm motion.

**Architecture:** A pure-TypeScript retrieval engine (`src/engine/`) runs lexical, vector and RRF retrieval, a k-hop graph walk and templated answer synthesis over a bundled JSON graph. It sits behind a `ChatClient` event-stream seam (`src/client/`), so a real `POST /chat` backend can be added later. A React UI (`src/ui/`) is driven by one store (`src/store/`) that persists to localStorage.

**Tech Stack:** React 19, TypeScript (strict), Vite, React Router (HashRouter), motion (`motion/react`), d3-force, d3-hierarchy, three, marked, DOMPurify, lucide-react, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-27-dummy-rag-design.md`. Read it before any task.

## Global Constraints

- No network calls at runtime other than Google Fonts (Inter). Nothing leaves the browser.
- localStorage keys are namespaced `dummy-rag.*`: `dummy-rag.theme`, `dummy-rag.graph-variant`, `dummy-rag.settings`, `dummy-rag.conversations`. Every read and write is wrapped in try/catch.
- Light tokens: bg `#f7f5f0`, side `#efece5`, panel `#ffffff`, line `#e3ded3`, ink `#2b2925`, accent `#b5522d`. Serif headlines (Georgia stack), Inter body.
- Dark tokens: bg radial-gradient(120% 90% at 70% 0%, `#1b2140` 0%, `#0b0d17` 60%), panels white at 3–5% with backdrop blur, line `rgba(255,255,255,.08)`, ink `#e6e8f2`, accent `#9aa6ff`, composer focus glow `0 0 28px rgba(124,140,255,.18)`. Inter throughout.
- Motion easing `cubic-bezier(.2,.8,.2,1)`, 200–600 ms, no bounce. Theme cross-fade about 500 ms. Message rise 8 px; chips delayed 250 ms. Dark-only ambient node drift. `prefers-reduced-motion: reduce` disables all motion.
- All entities are fictional. The UI shows "Fictional data for demonstration. Not financial or legal advice."
- Do not copy Lattice code, copy text or assets. The deployed Lattice bundle (`~/Work/lattice-extract/deployed`) may be read to settle open behaviours. The upstream source (`~/Work/lattice-extract/source`) may be read **only in Task 14**.
- Layout: sidebar | chat | evidence column (approved prototype; deviates from Lattice's inline evidence). The evidence column shows the **selected** assistant turn, which defaults to the latest; clicking an assistant message selects it. Below 1100 px the evidence column becomes a toggleable drawer; below 760 px the sidebar becomes a drawer.

## Review Focus

1. **localStorage blocked, or holding corrupt JSON:** the app loads with defaults and never throws. Test in Task 7.
2. **A question with no graph entities, empty input, or whitespace only:** whitespace never sends; no-entity questions get "No matching facts in the graph." with empty evidence tabs that render their empty states. Tests in Tasks 5 and 9.
3. **Switching or deleting a conversation while an answer streams:** the stream is aborted, and no tokens land in another conversation. Test in Task 7.
4. **A pronoun follow-up with Context off:** the question is not rewritten, and no "resolved:" line is shown. Test in Task 5.
5. **WebGL unavailable or a 3D chunk failing to load:** the 3D view shows an inline fallback message, and the other views still work. Test in Task 12.

## Core contract (defined in Task 2, used everywhere)

```ts
// src/domain/types.ts
export type NodeLabel = 'Person'|'Company'|'Account'|'Transaction'|'Address'|'Device'|'SanctionsEntry'|'Jurisdiction'|'Regulation'|'Case'|'Alert'|'Document'|'Section';
export type RelType = 'OWNS'|'DIRECTOR_OF'|'CONTROLS'|'HOLDS'|'SENT'|'RECEIVED'|'REGISTERED_AT'|'USED_DEVICE'|'MATCHES'|'INCORPORATED_IN'|'GOVERNED_BY'|'SUBJECT_OF'|'FLAGS'|'HAS_SECTION';
export interface GNode { id: string; label: NodeLabel; name: string; aliases?: string[]; jurisdiction?: string; props: Record<string, string|number|boolean>; }
export interface GRel  { id: string; type: RelType; from: string; to: string; confidence: number; section_id: string|null; props: Record<string, string|number>; }
export interface Section { id: string; document_id: string; title: string; text: string; }
export interface DocumentMeta { id: string; kind: 'registry'|'kyc'|'case-note'|'sar'|'sanctions'|'regulation'; title: string; date: string; }
export interface World { nodes: GNode[]; rels: GRel[]; documents: DocumentMeta[]; sections: Section[]; }

export type Source = 'live'|'offline';
export type Mode = 'lexical'|'vector'|'hybrid'|'graph';
export interface Settings { source: Source; mode: Mode; useContext: boolean; generateAnswer: boolean; }
export type StageId = 'context'|'lexical'|'vector'|'fuse'|'seeds'|'expand'|'rank'|'passages'|'generate'|'extractive';
export interface TraceStage { id: StageId; title: string; ms: number; detail: string; }
export interface Fact { rel_id: string; subject: string; relation: RelType; object: string; confidence: number; section_id: string|null; used: boolean; }
export interface CypherStep { stage: StageId; query: string; explain: string; }
export interface Subgraph { nodes: (GNode & { used: boolean; seed: boolean })[]; edges: (GRel & { used: boolean })[]; }
export interface ChatResponse {
  answer: string;              // markdown, citations as [n]
  citations: { n: number; section_id: string }[];
  facts: Fact[]; sources: Section[]; cypher: CypherStep[]; trace: TraceStage[];
  subgraph: Subgraph; confidence: number; resolvedQuestion: string|null;
  followUps: string[]; stats: { totalMs: number; settings: Settings };
}
export interface ChatRequest { question: string; history: { role: 'user'|'assistant'; text: string }[]; settings: Settings; }
export type ChatEvent =
  | { type: 'stage'; stage: TraceStage }
  | { type: 'token'; text: string }
  | { type: 'done'; response: ChatResponse }
  | { type: 'error'; message: string };
```

### Task 5: Pipeline, intents, answers, Cypher

**Files:**
- Create: `src/engine/context.ts`, `src/engine/intents.ts`, `src/engine/answer.ts`, `src/engine/cypher.ts`, `src/engine/pipeline.ts`
- Test: `src/engine/pipeline.test.ts`

**Interfaces:**
- Consumes: Tasks 3 and 4.
- Produces:
  - `resolveContext(question, history): { resolved: string; changed: boolean; detail: string }`. When nothing changes, `detail` reads "No pronouns or ellipsis to resolve."
  - `classify(q): Intent`, where `Intent = 'ownership'|'shared'|'sanctions'|'trail'|'flagged'|'regulation'|'profile'`.
  - `runPipeline(w, req: ChatRequest): { stages: TraceStage[]; response: ChatResponse }`. It is pure and synchronous. Timings are simulated latencies computed by the client, so `ms` here is 0.

**Pipeline behaviour:**
- Stages run in the order context → lexical → vector → fuse → seeds → expand → rank → passages → generate|extractive.
- Mode `lexical` skips vector and fuse. Mode `vector` skips lexical and fuse. Mode `hybrid` runs both and fuses. Mode `graph` runs hybrid plus expansion with hops=3; the other modes use hops=1.
- Each intent fixes the rel types to traverse and an answer template:
  - `ownership`: OWNS, CONTROLS, DIRECTOR_OF. Compute the UBO as the product of `pct` along the path.
  - `shared`: REGISTERED_AT, USED_DEVICE, DIRECTOR_OF.
  - `sanctions`: any type, hops ≤3; must end at a `SanctionsEntry`. Report the path and the `MATCHES` score.
  - `trail`: HOLDS, SENT, RECEIVED. Ordered by date.
  - `flagged`: FLAGS, SENT, RECEIVED.
  - `regulation`: GOVERNED_BY, INCORPORATED_IN.
  - `profile`: all types, hops=1.
- If the intent template has no facts but seeds exist, return an extractive answer of the top facts. If there are no seeds, the answer is exactly "No matching facts in the graph." with empty facts and an empty subgraph.
- `generateAnswer=false` uses stage `extractive` with detail "Returned the grounding facts verbatim without an LLM pass.", and the answer is a bullet list of facts with citations.
- `confidence` is the mean confidence of the used facts, rounded to 2 places (0 when there are none).
- Each assistant response has 3 `followUps`, chosen per intent and naming the focal entity.
- `cypher.ts` emits one `CypherStep` per executed stage. Queries use `db.index.fulltext.queryNodes('entityNames', $q)`, `db.index.vector.queryNodes('entityEmbeddings', 12, $embedding)`, `apoc.path.subgraphAll(seed, {maxLevel: $hops, relationshipFilter: '<TYPES joined by |>', labelFilter: '-Section|-Document'})`, a jurisdiction `WHERE`, and the passage join `MATCH (s:Section {id: r.section_id})`. Literal values are inlined as parameters in comments.
